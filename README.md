# Terroir — Restaurant Digital Experience

Une interface web moderne pour un restaurant haut de gamme basé à Abidjan, combinant design élégant, navigation dynamique et expérience utilisateur fluide.

---

## Aperçu du projet

**Terroir** est un site web interactif composé de :
- Une page d’accueil immersive
- Un menu dynamique filtrable
- Un système de navigation interne sans rechargement
- Un formulaire de réservation
